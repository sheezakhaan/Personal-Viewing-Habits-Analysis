# Personal Viewing Habits Analysis

> This project used Exploratory Data Analysis (EDA) to investigate my personal viewing history and identify patterns and trends in my viewing habits.

## Table of Contents

1. [Installation](#installation)
2. [Project Motivation](#project-motivation)
3. [Results](#results)

## Installation

The analysis was completed using Python and Jupyter Notebook.

The main libraries used are:

* Pandas
* NumPy
* Matplotlib

## Project Motivation

For this project, I was interested in using my personal viewing-history data to better understand:

1. What have I watched?
2. How much have I watched?
3. Has my viewing behaviour changed over time?
4. Has my taste changed over time?
